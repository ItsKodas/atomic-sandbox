# User data — Model library and Settings profiles: Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** One per-user data folder, holding two things.
- **The model library.** There is one surrogate model per Kohn-Sham surface and species set. The model is chosen from the scene, saved automatically, and switching between models is announced. Models survive restarts and crashes. The Model tab says what the current model is.
- **Settings profiles.** Named profiles, a default profile applied at launch, a Reset to factory settings, and an option to reopen the last scene (off by default).

Both share one atomic-write and lock layer.

**Architecture:**
- **New crate `userdata`** (std only): root resolution, atomic writes, file locks, JSON (moved out of `surrogate::sidecar`), FNV-1a, `utc_label`.
- **`surrogate`:** sidecar v4, `library::{LibraryKey, Library, Writer}`, and the file-level `sidecar::merge`.
- **`providers::ks`:** `TEACHER_REV`.
- **`providers::surrogate`:** records its history and encodes/decodes v4 behind four new `Trainable` methods.
- **`app::worker`:** replaces the session autosave with key resolution, switching, writer-thread saves, leases and `Command::SetSceneSettings`.
- **`app::settings` and `app::profiles`:** the settings inventory, profile JSON, and the apply path. Applying a profile uses the existing controls' commands.
- **`validate`:** gains the `TEACHER_REV` tripwire.
- No physics changes.

**Tech Stack:** Rust, std only. No new external crates: `std::fs::File::try_lock` (Rust 1.89, toolchain 1.99); FNV-1a and the civil-date conversion are hand-written.

**Spec:** `docs/superpowers/specs/2026-10-15-user-data-design.md` (section numbers below are the spec's). It was revised after review: `docs/superpowers/notes/2026-10-15-user-data-spec-review.md`, and spec §20 lists each MUST and the change. ## Global Constraints

- **Rule 1:** no per-element data is added. Label symbols are display data (`units::isotopes::symbol`).
- **Rule 2:** std only. No `serde`, `dirs`, `chrono` or `fs2`.
- **Rule 3:** atomic units in files and in the readouts' sources. Å and eV appear only at the UI edge.
- **Rule 5:** `sim` sees bytes and plain records across `Trainable`. It never sees a file format or a path policy.
- **Rule 6:** two gates.
  - Task 4a touches the store and the provenance gate, so `cargo test -p validate --release --test surrogate` must reproduce the M6 handoff's numbers to the printed digits.
  - The new `--test tripwire` joins the solver gate. A solver change must either keep it green or bump `TEACHER_REV` and add a `references.md` row.
- **Rule 7: the teacher revision.** `providers::ks::TEACHER_REV: u32` (1) is part of `Provenance` and of the key. Any change to the teacher's output bumps it. The tripwire enforces this, and the pseudopotential milestone will bump it to 2. The rule goes into `providers::ks`'s module doc and `references.md` § Surrogate.
- **Canonical inputs (review M2).** Every h and σ entering a scene goes through `app::scene::snap_length` (`format!("{:.6}")` → parse). The σ control has `fixed_decimals(3)`.
- **Rule 8:** a profile's `run.speed` is steps per tick, never dt.
- **Samples are never discarded silently.** Every save failure produces a Log error, a toast and a red line, and the bytes stay in memory until they land. **Only the lease holder writes, renames or quarantines an entry. Only `InvalidData` is corruption** (review M1).
- **Tests and automation never touch the real user data.** `userdata::default_root()` is called only from `main.rs`, and only when none of `--screenshot`/`--record`/`--replay` is given without `--data-dir`. Every test passes a temp directory. Task 5's grep step checks this.
- **One source of truth for factory settings:** `UiState::new` is built from `Settings::factory()` (Task 8).
- **Determinism:** FNV-1a and `{:?}` floats only. `DefaultHasher` is forbidden for anything written to disk.
- **Timings** (save cost, switch cost) are reported, never asserted.
- **Keep README.md current** (CLAUDE.md user instruction). Tasks 7b and 9 update it in the same commit. Task 7b rewrites CLAUDE.md's model-files sentences.
- **Commit with `git commit -o -- <paths>`** (memory rule: an implementer may share the checkout).

   - Task 5 `a_second_worker_on_a_leased_entry_is_read_only_and_merges_when_the_lease_frees`

   - Task 3 `the_canonical_key_and_its_hash_are_pinned`
   - Task 3 `the_key_is_bit_exact_and_agrees_with_the_provenance_gate`

   - Task 5 `a_key_change_mid_pass_cancels_the_pass_into_the_old_entry`
