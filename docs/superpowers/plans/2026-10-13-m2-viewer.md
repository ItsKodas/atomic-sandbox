# M2 — Viewer Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A windowed 3D viewer in which the user places nuclei, the M1 CPU solver computes the electron density on a worker thread, and the density is drawn as a volume (with nuclei as spheres) that the user can orbit — the first interactive picture, feeding every later milestone's rendering.

**Architecture:** Three new crates. `gpu` owns the wgpu device/queue, surface, a 3D float texture for the density, and typed uniform/instance buffers. `render` owns the orbit camera, an instanced impostor-sphere pass for nuclei, and a fullscreen raymarch pass for the density (volume or isosurface) composited with the sphere depth. `app` owns the winit window, the egui side panel and tools, the scene text format and presets, and a simulation worker thread that wraps `qm::scf` behind a command/snapshot channel pair so the render loop never blocks on an SCF. The GPU solver (M3) will later replace the worker's CPU solve and write the density texture directly; nothing in `render` changes for that.

**Tech Stack:** Rust 2021; `wgpu = "30"`, `winit = "0.30"`, `egui = "0.36"`, `egui-wgpu = "0.36"`, `egui-winit = "0.36"`, `glam = "0.34"`, `bytemuck = "1"`, `pollster = "1"`. WGSL shaders embedded with `include_str!`. No other new crates.

**Spec:** `docs/superpowers/specs/2026-10-12-atomic-sandbox-design.md` (§5 architecture, §7 threading, §8 tooling & rendering). Milestone order was re-sequenced on 2026-10-13 (viewer before GPU solver) by controller ruling; this plan implements spec §8 on top of the M1 CPU solver.

**Model tags:** every task is **[Opus]** (`claude-opus-5-5`) — graphics plumbing and UI with well-specified behaviour. The only physics-facing piece (the sim worker, Task 6) touches `qm` through its public API only; physics-review is not required, but the reviewer must check that the worker never mutates physics settings silently.

## Global Constraints

- Display-only per-element data (colour, sphere radius) lives in `render::elements` and nowhere else; `qm` stays Z + mass only.
- Atomic units cross the `qm` boundary; the viewer converts for labels via `units` only. World space in the renderer is Bohr.
- The render thread never calls `qm::scf`. All solves run on the sim worker; results arrive as immutable `Snapshot`s.
- The density volume on the GPU is `r32float`, uploaded from the snapshot's `Vec<f32>`; conversion f64→f32 happens once, on the worker, after the solve.
- Grid index layout `i + n0*(j + n1*k)` is the texture layout: x fastest, then y, then z.
- Headless GPU tests create a device with `pollster::block_on` and `wgpu::Instance::default()`; they must pass on the RX 7900 XTX (Vulkan) and be `#[ignore]`d with a reason if no adapter is found at runtime — never hard-fail on a machine without a GPU.
- `cargo run -p app --release` is the entry point; debug builds are acceptable for the UI but the SCF is ~10× slower there, so CLAUDE.md documents `--release`.
- Commits end with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.

## Review Focus

1. **A solve that fails** (`QmError::ScfNotConverged`, or a panic inside `qm` for a user-placed geometry such as two nuclei on the same point) must not kill the worker or the window: the UI shows the error, the last good snapshot stays on screen. Pinned in Task 6 and Task 7.
2. **Changing the grid while a solve is running**: the in-flight snapshot has the old grid; the texture must be re-created at the new size, never written with a mismatched length. Pinned in Task 6 (worker coalescing) and Task 7 (upload guard).
3. **Window resize to zero** (minimise) must not panic in `surface.configure`. Pinned in Task 7.
4. **Density scale**: a hydrogen atom (peak ρ ≈ 0.3) and an H₂O (peak ≈ 300 at an O nucleus) must both be visible without the user tuning anything — auto-scale from the snapshot's max with a power-law transfer function. Pinned in Task 4 (shader uniform) and Task 7 (auto-scale on new snapshot).
5. **Picking the wrong nucleus** when two overlap on screen: pick the nearest along the ray, not the first in the list. Pinned in Task 7.

// crates/gpu/src/lib.rs
//! wgpu plumbing shared by the renderer and (later) the GPU solver. Nothing here knows about physics.
pub mod volume;
pub use volume::Volume3D;
use std::marker::PhantomData;

pub const DEPTH_FORMAT: wgpu::TextureFormat = wgpu::TextureFormat::Depth32Float;

pub struct GpuContext { pub instance: wgpu::Instance, pub adapter: wgpu::Adapter, pub device: wgpu::Device, pub queue: wgpu::Queue }

impl GpuContext {
    fn request(instance: wgpu::Instance, surface: Option<&wgpu::Surface<'_>>) -> Option<GpuContext> {
        let adapter = pollster::block_on(instance.request_adapter(&wgpu::RequestAdapterOptions {
            power_preference: wgpu::PowerPreference::HighPerformance,
            compatible_surface: surface,
            force_fallback_adapter: false,
        })).ok()?;
        let (device, queue) = pollster::block_on(adapter.request_device(&wgpu::DeviceDescriptor {
            label: Some("atomic-sandbox"),
            required_features: wgpu::Features::empty(),
            required_limits: wgpu::Limits::default(),
            ..Default::default()
        })).ok()?;
        Some(GpuContext { instance, adapter, device, queue })
    }
    pub fn new_headless() -> Option<GpuContext> {
        Self::request(wgpu::Instance::default(), None)
    }
    pub fn new_for_surface(target: wgpu::SurfaceTarget<'static>) -> Option<(GpuContext, wgpu::Surface<'static>)> {
        let instance = wgpu::Instance::default();
        let surface = instance.create_surface(target).ok()?;
        let ctx = Self::request(instance, Some(&surface))?;
        Some((ctx, surface))
    }
}

pub struct SurfaceState { pub surface: wgpu::Surface<'static>, pub config: wgpu::SurfaceConfiguration, pub depth: wgpu::TextureView }

impl SurfaceState {
    pub fn new(ctx: &GpuContext, surface: wgpu::Surface<'static>, width: u32, height: u32) -> SurfaceState {
        let caps = surface.get_capabilities(&ctx.adapter);
        let format = caps.formats.iter().copied().find(|f| f.is_srgb()).unwrap_or(caps.formats[0]);
        let config = wgpu::SurfaceConfiguration {
            usage: wgpu::TextureUsages::RENDER_ATTACHMENT, format,
            width: width.max(1), height: height.max(1),
            present_mode: wgpu::PresentMode::AutoVsync, alpha_mode: caps.alpha_modes[0],
            view_formats: vec![], desired_maximum_frame_latency: 2,
        };
        surface.configure(&ctx.device, &config);
        let depth = Self::make_depth(ctx, config.width, config.height);
        SurfaceState { surface, config, depth }
    }
    fn make_depth(ctx: &GpuContext, w: u32, h: u32) -> wgpu::TextureView {
        ctx.device.create_texture(&wgpu::TextureDescriptor {
            label: Some("depth"), size: wgpu::Extent3d { width: w, height: h, depth_or_array_layers: 1 },
            mip_level_count: 1, sample_count: 1, dimension: wgpu::TextureDimension::D2, format: DEPTH_FORMAT,
            usage: wgpu::TextureUsages::RENDER_ATTACHMENT | wgpu::TextureUsages::TEXTURE_BINDING, view_formats: &[],
        }).create_view(&Default::default())
    }
    pub fn resize(&mut self, ctx: &GpuContext, width: u32, height: u32) {
        if width == 0 || height == 0 { return; }
        self.config.width = width; self.config.height = height;
        self.surface.configure(&ctx.device, &self.config);
        self.depth = Self::make_depth(ctx, width, height);
    }
}

pub struct UniformBuffer<T: bytemuck::Pod> { pub buffer: wgpu::Buffer, _t: PhantomData<T> }
impl<T: bytemuck::Pod> UniformBuffer<T> {
    pub fn new(ctx: &GpuContext, label: &str) -> Self {
        let buffer = ctx.device.create_buffer(&wgpu::BufferDescriptor {
            label: Some(label), size: std::mem::size_of::<T>() as u64,
            usage: wgpu::BufferUsages::UNIFORM | wgpu::BufferUsages::COPY_DST, mapped_at_creation: false,
        });
        UniformBuffer { buffer, _t: PhantomData }
    }
    pub fn write(&self, ctx: &GpuContext, value: &T) { ctx.queue.write_buffer(&self.buffer, 0, bytemuck::bytes_of(value)); }
}

// crates/gpu/src/volume.rs
//! 3D r32float texture holding a scalar field in grid layout i + nx*(j + ny*k) (x fastest).
use crate::GpuContext;

pub struct Volume3D { pub texture: wgpu::Texture, pub view: wgpu::TextureView, pub sampler: wgpu::Sampler, pub dims: [u32; 3] }

impl Volume3D {
    pub fn new(ctx: &GpuContext, dims: [u32; 3]) -> Volume3D {
        let texture = ctx.device.create_texture(&wgpu::TextureDescriptor {
            label: Some("density volume"),
            size: wgpu::Extent3d { width: dims[0], height: dims[1], depth_or_array_layers: dims[2] },
            mip_level_count: 1, sample_count: 1, dimension: wgpu::TextureDimension::D3,
            format: wgpu::TextureFormat::R32Float,
            usage: wgpu::TextureUsages::TEXTURE_BINDING | wgpu::TextureUsages::COPY_DST | wgpu::TextureUsages::COPY_SRC,
            view_formats: &[],
        });
        let view = texture.create_view(&Default::default());
        let sampler = ctx.device.create_sampler(&wgpu::SamplerDescriptor {
            label: Some("volume sampler"),
            address_mode_u: wgpu::AddressMode::ClampToEdge, address_mode_v: wgpu::AddressMode::ClampToEdge, address_mode_w: wgpu::AddressMode::ClampToEdge,
            mag_filter: wgpu::FilterMode::Linear, min_filter: wgpu::FilterMode::Linear, ..Default::default()
        });
        Volume3D { texture, view, sampler, dims }
    }

    pub fn len(&self) -> usize { (self.dims[0] * self.dims[1] * self.dims[2]) as usize }

    pub fn upload(&self, ctx: &GpuContext, data: &[f32]) {
        assert_eq!(data.len(), self.len(), "Volume3D::upload: data length {} != dims {:?}", data.len(), self.dims);
        ctx.queue.write_texture(
            wgpu::TexelCopyTextureInfo { texture: &self.texture, mip_level: 0, origin: wgpu::Origin3d::ZERO, aspect: wgpu::TextureAspect::All },
            bytemuck::cast_slice(data),
            wgpu::TexelCopyBufferLayout { offset: 0, bytes_per_row: Some(4 * self.dims[0]), rows_per_image: Some(self.dims[1]) },
            wgpu::Extent3d { width: self.dims[0], height: self.dims[1], depth_or_array_layers: self.dims[2] },
        );
    }

    /// Headless readback for tests. Rows are padded to COPY_BYTES_PER_ROW_ALIGNMENT in the staging buffer.
    pub fn read_back(&self, ctx: &GpuContext) -> Vec<f32> {
        let row_bytes = 4 * self.dims[0];
        let align = wgpu::COPY_BYTES_PER_ROW_ALIGNMENT;
        let padded = row_bytes.div_ceil(align) * align;
        let size = (padded * self.dims[1] * self.dims[2]) as u64;
        let staging = ctx.device.create_buffer(&wgpu::BufferDescriptor {
            label: Some("volume readback"), size, usage: wgpu::BufferUsages::COPY_DST | wgpu::BufferUsages::MAP_READ, mapped_at_creation: false,
        });
        let mut enc = ctx.device.create_command_encoder(&Default::default());
        enc.copy_texture_to_buffer(
            wgpu::TexelCopyTextureInfo { texture: &self.texture, mip_level: 0, origin: wgpu::Origin3d::ZERO, aspect: wgpu::TextureAspect::All },
            wgpu::TexelCopyBufferInfo { buffer: &staging, layout: wgpu::TexelCopyBufferLayout { offset: 0, bytes_per_row: Some(padded), rows_per_image: Some(self.dims[1]) } },
            wgpu::Extent3d { width: self.dims[0], height: self.dims[1], depth_or_array_layers: self.dims[2] },
        );
        ctx.queue.submit([enc.finish()]);
        let slice = staging.slice(..);
        let (tx, rx) = std::sync::mpsc::channel();
        slice.map_async(wgpu::MapMode::Read, move |r| { let _ = tx.send(r); });
        ctx.device.poll(wgpu::PollType::wait_indefinitely()).expect("poll");
        rx.recv().expect("map callback").expect("map ok");
        let bytes = slice.get_mapped_range();
        let mut out = Vec::with_capacity(self.len());
        for z in 0..self.dims[2] { for y in 0..self.dims[1] {
            let start = ((z * self.dims[1] + y) * padded) as usize;
            out.extend_from_slice(bytemuck::cast_slice(&bytes[start..start + row_bytes as usize]));
        }}
        drop(bytes); staging.unmap();
        out
    }
}

//! Orbit camera in world units (Bohr). Right-handed, +y up; wgpu clip space (depth 0..1).
use glam::{Mat4, Vec3};

pub struct OrbitCamera { pub target: Vec3, pub yaw: f32, pub pitch: f32, pub distance: f32, pub fov_y: f32, pub near: f32, pub far: f32 }

impl OrbitCamera {
    pub fn new(target: Vec3, distance: f32) -> OrbitCamera {
        OrbitCamera { target, yaw: 0.6, pitch: 0.35, distance, fov_y: 50f32.to_radians(), near: 0.05, far: 500.0 }
    }
    fn forward(&self) -> Vec3 {
        // direction from eye to target
        -Vec3::new(self.pitch.cos() * self.yaw.sin(), self.pitch.sin(), self.pitch.cos() * self.yaw.cos())
    }
    pub fn eye(&self) -> Vec3 { self.target - self.forward() * self.distance }
    pub fn view(&self) -> Mat4 { Mat4::look_at_rh(self.eye(), self.target, Vec3::Y) }
    pub fn proj(&self, aspect: f32) -> Mat4 { Mat4::perspective_rh(self.fov_y, aspect, self.near, self.far) }
    pub fn view_proj(&self, aspect: f32) -> Mat4 { self.proj(aspect) * self.view() }
    pub fn orbit(&mut self, dx_px: f32, dy_px: f32) {
        self.yaw -= dx_px * 0.005;
        self.pitch = (self.pitch + dy_px * 0.005).clamp(-1.5, 1.5);
    }
    pub fn zoom(&mut self, scroll_lines: f32) { self.distance = (self.distance * 0.9f32.powf(scroll_lines)).max(0.5); }
    pub fn pan(&mut self, dx_px: f32, dy_px: f32, height_px: f32) {
        let world_per_px = 2.0 * self.distance * (self.fov_y / 2.0).tan() / height_px;
        let f = self.forward();
        let right = f.cross(Vec3::Y).normalize();
        let up = right.cross(f).normalize();
        self.target += (-right * dx_px + up * dy_px) * world_per_px;
    }
    pub fn focus(&mut self, point: Vec3) { self.target = point; }
    pub fn pixel_ray(&self, px: f32, py: f32, width_px: f32, height_px: f32) -> (Vec3, Vec3) {
        let ndc_x = 2.0 * px / width_px - 1.0;
        let ndc_y = 1.0 - 2.0 * py / height_px;
        let inv = (self.proj(width_px / height_px) * self.view()).inverse();
        let near = inv.project_point3(Vec3::new(ndc_x, ndc_y, 0.0));
        let far = inv.project_point3(Vec3::new(ndc_x, ndc_y, 1.0));
        (self.eye(), (far - near).normalize())
    }
    pub fn focus_plane(&self) -> (Vec3, Vec3) { (self.target, -self.forward()) }
}

pub fn ray_plane(origin: Vec3, dir: Vec3, point: Vec3, normal: Vec3) -> Option<Vec3> {
    let denom = dir.dot(normal);
    if denom.abs() < 1e-8 { return None; }
    let t = (point - origin).dot(normal) / denom;
    if t < 0.0 { None } else { Some(origin + dir * t) }
}

pub fn ray_sphere(origin: Vec3, dir: Vec3, centre: Vec3, radius: f32) -> Option<f32> {
    let oc = origin - centre;
    let b = oc.dot(dir);
    let c = oc.dot(oc) - radius * radius;
    let disc = b * b - c;
    if disc < 0.0 { return None; }
    let s = disc.sqrt();
    let t0 = -b - s;
    let t1 = -b + s;
    if t0 >= 0.0 { Some(t0) } else if t1 >= 0.0 { Some(t1) } else { None }
}

// shaders/spheres.wgsl
struct Camera { view_proj: mat4x4<f32>, inv_view_proj: mat4x4<f32>, eye: vec3<f32>, _p0: f32, viewport: vec2<f32>, _p1: vec2<f32> };
@group(0) @binding(0) var<uniform> cam: Camera;

struct Inst { @location(0) centre: vec3<f32>, @location(1) radius: f32, @location(2) colour: vec3<f32>, @location(3) selected: f32 };
struct VOut { @builtin(position) pos: vec4<f32>, @location(0) centre: vec3<f32>, @location(1) radius: f32, @location(2) colour: vec3<f32>, @location(3) selected: f32 };

@vertex
fn vs_main(@builtin(vertex_index) vi: u32, inst: Inst) -> VOut {
    var corners = array<vec2<f32>, 6>(vec2(-1.0,-1.0), vec2(1.0,-1.0), vec2(1.0,1.0), vec2(-1.0,-1.0), vec2(1.0,1.0), vec2(-1.0,1.0));
    let c = corners[vi % 6u];
    // camera right/up from the inverse view-projection (world-space directions of clip x/y)
    let right = normalize((cam.inv_view_proj * vec4(1.0, 0.0, 0.0, 0.0)).xyz);
    let up = normalize((cam.inv_view_proj * vec4(0.0, 1.0, 0.0, 0.0)).xyz);
    // enlarge by 1.15 so the perspective silhouette never leaves the quad
    let world = inst.centre + (right * c.x + up * c.y) * inst.radius * 1.15;
    var o: VOut;
    o.pos = cam.view_proj * vec4(world, 1.0);
    o.centre = inst.centre; o.radius = inst.radius; o.colour = inst.colour; o.selected = inst.selected;
    return o;
}

struct FOut { @location(0) colour: vec4<f32>, @builtin(frag_depth) depth: f32 };

@fragment
fn fs_main(in: VOut) -> FOut {
    let ndc = vec2(in.pos.x / cam.viewport.x * 2.0 - 1.0, 1.0 - in.pos.y / cam.viewport.y * 2.0);
    let p_near = cam.inv_view_proj * vec4(ndc, 0.0, 1.0);
    let p_far = cam.inv_view_proj * vec4(ndc, 1.0, 1.0);
    let o = p_near.xyz / p_near.w;
    let d = normalize(p_far.xyz / p_far.w - o);
    let oc = o - in.centre;
    let b = dot(oc, d);
    let cc = dot(oc, oc) - in.radius * in.radius;
    let disc = b * b - cc;
    if (disc < 0.0) { discard; }
    let t = -b - sqrt(disc);
    if (t < 0.0) { discard; }
    let hit = o + d * t;
    let n = normalize(hit - in.centre);
    let l = -d;
    let diffuse = max(dot(n, l), 0.0);
    let rim = pow(1.0 - max(dot(n, l), 0.0), 3.0);
    var col = in.colour * (0.15 + 0.85 * diffuse) + vec3(0.25) * rim;
    if (in.selected > 0.5) { col = mix(col, vec3(1.0, 0.9, 0.3), rim * 0.9 + 0.1); }
    let clip = cam.view_proj * vec4(hit, 1.0);
    var out: FOut;
    out.colour = vec4(col, 1.0);
    out.depth = clip.z / clip.w;
    return out;
}

// spheres.rs
//! Instanced impostor spheres: one camera-facing quad per nucleus, analytic ray-sphere in the fragment shader,
//! true sphere depth written so the volume pass can composite against it.
use crate::camera::OrbitCamera;
use gpu::{GpuContext, UniformBuffer, DEPTH_FORMAT};

#[repr(C)] #[derive(Clone, Copy, bytemuck::Pod, bytemuck::Zeroable)]
pub struct SphereInstance { pub centre: [f32; 3], pub radius: f32, pub colour: [f32; 3], pub selected: f32 }

#[repr(C)] #[derive(Clone, Copy, bytemuck::Pod, bytemuck::Zeroable)]
pub struct CameraUniform { pub view_proj: [[f32; 4]; 4], pub inv_view_proj: [[f32; 4]; 4], pub eye: [f32; 3], pub _pad0: f32, pub viewport: [f32; 2], pub _pad1: [f32; 2] }

impl CameraUniform {
    pub fn from_camera(c: &OrbitCamera, width: f32, height: f32) -> CameraUniform {
        let vp = c.view_proj(width / height);
        CameraUniform { view_proj: vp.to_cols_array_2d(), inv_view_proj: vp.inverse().to_cols_array_2d(), eye: c.eye().to_array(), _pad0: 0.0, viewport: [width, height], _pad1: [0.0; 2] }
    }
}

pub struct SpherePass { pipeline: wgpu::RenderPipeline, bind_group: wgpu::BindGroup, instances: wgpu::Buffer, capacity: usize, count: u32 }

impl SpherePass {
    pub fn new(ctx: &GpuContext, colour_format: wgpu::TextureFormat, camera: &UniformBuffer<CameraUniform>) -> SpherePass {
        let shader = ctx.device.create_shader_module(wgpu::ShaderModuleDescriptor { label: Some("spheres"), source: wgpu::ShaderSource::Wgsl(include_str!("shaders/spheres.wgsl").into()) });
        let bgl = ctx.device.create_bind_group_layout(&wgpu::BindGroupLayoutDescriptor { label: Some("camera bgl"), entries: &[wgpu::BindGroupLayoutEntry {
            binding: 0, visibility: wgpu::ShaderStages::VERTEX_FRAGMENT,
            ty: wgpu::BindingType::Buffer { ty: wgpu::BufferBindingType::Uniform, has_dynamic_offset: false, min_binding_size: None }, count: None }] });
        let bind_group = ctx.device.create_bind_group(&wgpu::BindGroupDescriptor { label: Some("camera bg"), layout: &bgl, entries: &[wgpu::BindGroupEntry { binding: 0, resource: camera.buffer.as_entire_binding() }] });
        let layout = ctx.device.create_pipeline_layout(&wgpu::PipelineLayoutDescriptor { label: None, bind_group_layouts: &[&bgl], push_constant_ranges: &[] });
        let pipeline = ctx.device.create_render_pipeline(&wgpu::RenderPipelineDescriptor {
            label: Some("spheres"), layout: Some(&layout),
            vertex: wgpu::VertexState { module: &shader, entry_point: Some("vs_main"), compilation_options: Default::default(), buffers: &[wgpu::VertexBufferLayout {
                array_stride: std::mem::size_of::<SphereInstance>() as u64, step_mode: wgpu::VertexStepMode::Instance,
                attributes: &wgpu::vertex_attr_array![0 => Float32x3, 1 => Float32, 2 => Float32x3, 3 => Float32] }] },
            fragment: Some(wgpu::FragmentState { module: &shader, entry_point: Some("fs_main"), compilation_options: Default::default(), targets: &[Some(colour_format.into())] }),
            primitive: wgpu::PrimitiveState { topology: wgpu::PrimitiveTopology::TriangleList, cull_mode: None, ..Default::default() },
            depth_stencil: Some(wgpu::DepthStencilState { format: DEPTH_FORMAT, depth_write_enabled: true, depth_compare: wgpu::CompareFunction::Less, stencil: Default::default(), bias: Default::default() }),
            multisample: Default::default(), multiview: None, cache: None,
        });
        let instances = Self::make_buffer(ctx, 16);
        SpherePass { pipeline, bind_group, instances, capacity: 16, count: 0 }
    }
    fn make_buffer(ctx: &GpuContext, capacity: usize) -> wgpu::Buffer {
        ctx.device.create_buffer(&wgpu::BufferDescriptor { label: Some("sphere instances"), size: (capacity * std::mem::size_of::<SphereInstance>()) as u64, usage: wgpu::BufferUsages::VERTEX | wgpu::BufferUsages::COPY_DST, mapped_at_creation: false })
    }
    pub fn set_instances(&mut self, ctx: &GpuContext, instances: &[SphereInstance]) {
        if instances.len() > self.capacity { self.capacity = instances.len().next_power_of_two(); self.instances = Self::make_buffer(ctx, self.capacity); }
        if !instances.is_empty() { ctx.queue.write_buffer(&self.instances, 0, bytemuck::cast_slice(instances)); }
        self.count = instances.len() as u32;
    }
    pub fn draw<'a>(&'a self, pass: &mut wgpu::RenderPass<'a>) {
        if self.count == 0 { return; }
        pass.set_pipeline(&self.pipeline);
        pass.set_bind_group(0, &self.bind_group, &[]);
        pass.set_vertex_buffer(0, self.instances.slice(..));
        pass.draw(0..6, 0..self.count);
    }
}

// headless.rs
//! Render-to-texture harness for tests: Rgba8Unorm colour + Depth32Float, with CPU readback.
use gpu::{GpuContext, DEPTH_FORMAT};
pub const HEADLESS_FORMAT: wgpu::TextureFormat = wgpu::TextureFormat::Rgba8Unorm;

pub struct Headless { pub ctx: GpuContext, pub colour: wgpu::Texture, pub colour_view: wgpu::TextureView, pub depth: wgpu::TextureView, pub width: u32, pub height: u32 }

impl Headless {
    pub fn new(width: u32, height: u32) -> Option<Headless> {
        let ctx = GpuContext::new_headless()?;
        let size = wgpu::Extent3d { width, height, depth_or_array_layers: 1 };
        let colour = ctx.device.create_texture(&wgpu::TextureDescriptor { label: Some("headless colour"), size, mip_level_count: 1, sample_count: 1, dimension: wgpu::TextureDimension::D2, format: HEADLESS_FORMAT, usage: wgpu::TextureUsages::RENDER_ATTACHMENT | wgpu::TextureUsages::COPY_SRC, view_formats: &[] });
        let colour_view = colour.create_view(&Default::default());
        let depth = ctx.device.create_texture(&wgpu::TextureDescriptor { label: Some("headless depth"), size, mip_level_count: 1, sample_count: 1, dimension: wgpu::TextureDimension::D2, format: DEPTH_FORMAT, usage: wgpu::TextureUsages::RENDER_ATTACHMENT | wgpu::TextureUsages::TEXTURE_BINDING, view_formats: &[] }).create_view(&Default::default());
        Some(Headless { ctx, colour, colour_view, depth, width, height })
    }
    pub fn begin<'a>(&'a self, enc: &'a mut wgpu::CommandEncoder, clear: wgpu::Color) -> wgpu::RenderPass<'a> {
        enc.begin_render_pass(&wgpu::RenderPassDescriptor {
            label: Some("headless"),
            color_attachments: &[Some(wgpu::RenderPassColorAttachment { view: &self.colour_view, resolve_target: None, ops: wgpu::Operations { load: wgpu::LoadOp::Clear(clear), store: wgpu::StoreOp::Store }, depth_slice: None })],
            depth_stencil_attachment: Some(wgpu::RenderPassDepthStencilAttachment { view: &self.depth, depth_ops: Some(wgpu::Operations { load: wgpu::LoadOp::Clear(1.0), store: wgpu::StoreOp::Store }), stencil_ops: None }),
            timestamp_writes: None, occlusion_query_set: None,
        })
    }
    pub fn read_rgba(&self) -> Vec<[u8; 4]> {
        let row = 4 * self.width;
        let align = wgpu::COPY_BYTES_PER_ROW_ALIGNMENT;
        let padded = row.div_ceil(align) * align;
        let buf = self.ctx.device.create_buffer(&wgpu::BufferDescriptor { label: Some("readback"), size: (padded * self.height) as u64, usage: wgpu::BufferUsages::COPY_DST | wgpu::BufferUsages::MAP_READ, mapped_at_creation: false });
        let mut enc = self.ctx.device.create_command_encoder(&Default::default());
        enc.copy_texture_to_buffer(
            wgpu::TexelCopyTextureInfo { texture: &self.colour, mip_level: 0, origin: wgpu::Origin3d::ZERO, aspect: wgpu::TextureAspect::All },
            wgpu::TexelCopyBufferInfo { buffer: &buf, layout: wgpu::TexelCopyBufferLayout { offset: 0, bytes_per_row: Some(padded), rows_per_image: Some(self.height) } },
            wgpu::Extent3d { width: self.width, height: self.height, depth_or_array_layers: 1 });
        self.ctx.queue.submit([enc.finish()]);
        let slice = buf.slice(..);
        let (tx, rx) = std::sync::mpsc::channel();
        slice.map_async(wgpu::MapMode::Read, move |r| { let _ = tx.send(r); });
        self.ctx.device.poll(wgpu::PollType::wait_indefinitely()).expect("poll");
        rx.recv().unwrap().unwrap();
        let bytes = slice.get_mapped_range();
        let mut out = Vec::with_capacity((self.width * self.height) as usize);
        for y in 0..self.height { for x in 0..self.width {
            let i = (y * padded + 4 * x) as usize;
            out.push([bytes[i], bytes[i + 1], bytes[i + 2], bytes[i + 3]]);
        }}
        drop(bytes); buf.unmap();
        out
    }
}

Shader technique: fullscreen triangle; per pixel reconstruct the ray; intersect the axis-aligned box `[box_min, box_max]` (slab test); read the scene depth at this pixel and convert to a world distance along the ray so the march stops at the nearest sphere surface; march from t_enter to min(t_exit, t_sphere) in steps of `step`, sampling the 3D texture with normalised coordinates `(p − box_min)/(box_max − box_min)`; **volume mode**: s = pow(clamp(rho/scale, 0, 1), gamma), colour from a fixed 4-stop ramp (deep blue → magenta → orange → white), alpha = 1 − exp(−opacity·s·step), front-to-back compositing with early exit at α > 0.98; **isosurface mode**: find the first sample with rho/scale ≥ iso, refine by one bisection, normal from central differences of the texture, headlight shading, opaque. Output premultiplied colour with alpha; pipeline blend = premultiplied-over so the sphere colour shows through where the volume is thin.

// shaders/volume.wgsl
struct Camera { view_proj: mat4x4<f32>, inv_view_proj: mat4x4<f32>, eye: vec3<f32>, _p0: f32, viewport: vec2<f32>, _p1: vec2<f32> };
struct Params { box_min: vec3<f32>, mode: u32, box_max: vec3<f32>, scale: f32, gamma: f32, iso: f32, step: f32, opacity: f32 };
@group(0) @binding(0) var<uniform> cam: Camera;
@group(1) @binding(0) var<uniform> prm: Params;
@group(1) @binding(1) var vol: texture_3d<f32>;
@group(1) @binding(2) var samp: sampler;
@group(1) @binding(3) var scene_depth: texture_depth_2d;

struct VOut { @builtin(position) pos: vec4<f32> };
@vertex fn vs_main(@builtin(vertex_index) vi: u32) -> VOut {
    var p = array<vec2<f32>, 3>(vec2(-1.0, -1.0), vec2(3.0, -1.0), vec2(-1.0, 3.0));
    var o: VOut; o.pos = vec4(p[vi], 0.0, 1.0); return o;
}

fn ramp(s: f32) -> vec3<f32> {
    let c0 = vec3(0.05, 0.02, 0.25); let c1 = vec3(0.6, 0.1, 0.6); let c2 = vec3(1.0, 0.55, 0.15); let c3 = vec3(1.0, 1.0, 0.9);
    if (s < 0.33) { return mix(c0, c1, s / 0.33); }
    if (s < 0.66) { return mix(c1, c2, (s - 0.33) / 0.33); }
    return mix(c2, c3, (s - 0.66) / 0.34);
}
fn sample_rho(p: vec3<f32>) -> f32 {
    let uv = (p - prm.box_min) / (prm.box_max - prm.box_min);
    return textureSampleLevel(vol, samp, uv, 0.0).r;
}
fn depth_to_t(frag: vec2<f32>, o: vec3<f32>, d: vec3<f32>) -> f32 {
    let z = textureLoad(scene_depth, vec2<i32>(frag), 0);
    if (z >= 1.0) { return 1e30; }
    let ndc = vec2(frag.x / cam.viewport.x * 2.0 - 1.0, 1.0 - frag.y / cam.viewport.y * 2.0);
    let pw = cam.inv_view_proj * vec4(ndc, z, 1.0);
    return dot(pw.xyz / pw.w - o, d);
}

@fragment fn fs_main(in: VOut) -> @location(0) vec4<f32> {
    let ndc = vec2(in.pos.x / cam.viewport.x * 2.0 - 1.0, 1.0 - in.pos.y / cam.viewport.y * 2.0);
    let pn = cam.inv_view_proj * vec4(ndc, 0.0, 1.0);
    let pf = cam.inv_view_proj * vec4(ndc, 1.0, 1.0);
    let o = pn.xyz / pn.w;
    let d = normalize(pf.xyz / pf.w - o);
    // slab test
    let inv = 1.0 / d;
    let t0 = (prm.box_min - o) * inv; let t1 = (prm.box_max - o) * inv;
    let tmin = max(max(min(t0.x, t1.x), min(t0.y, t1.y)), min(t0.z, t1.z));
    let tmax = min(min(max(t0.x, t1.x), max(t0.y, t1.y)), max(t0.z, t1.z));
    let t_enter = max(tmin, 0.0);
    let t_exit = min(tmax, depth_to_t(in.pos.xy, o, d));
    if (t_exit <= t_enter) { return vec4(0.0); }
    var colour = vec3(0.0); var alpha = 0.0;
    var t = t_enter;
    if (prm.mode == 1u) {
        var prev = 0.0;
        loop {
            if (t > t_exit) { break; }
            let s = sample_rho(o + d * t) / prm.scale;
            if (s >= prm.iso) {
                // one bisection step
                let tb = t - prm.step * (s - prm.iso) / max(s - prev, 1e-6);
                let p = o + d * tb;
                let e = prm.step;
                let n = normalize(vec3(sample_rho(p + vec3(e,0.0,0.0)) - sample_rho(p - vec3(e,0.0,0.0)),
                                       sample_rho(p + vec3(0.0,e,0.0)) - sample_rho(p - vec3(0.0,e,0.0)),
                                       sample_rho(p + vec3(0.0,0.0,e)) - sample_rho(p - vec3(0.0,0.0,e))) * -1.0);
                let diffuse = max(dot(n, -d), 0.0);
                return vec4(ramp(prm.iso) * (0.2 + 0.8 * diffuse), 1.0);
            }
            prev = s; t = t + prm.step;
        }
        return vec4(0.0);
    }
    loop {
        if (t > t_exit || alpha > 0.98) { break; }
        let s = pow(clamp(sample_rho(o + d * t) / prm.scale, 0.0, 1.0), prm.gamma);
        let a = 1.0 - exp(-prm.opacity * s * prm.step);
        colour = colour + (1.0 - alpha) * a * ramp(s);
        alpha = alpha + (1.0 - alpha) * a;
        t = t + prm.step;
    }
    return vec4(colour, alpha); // premultiplied
}

//! Scene text format v1 (see module tests for the grammar) and embedded presets.
#[derive(Clone, Debug, PartialEq)]
pub struct SceneNucleus { pub z: u8, pub pos: [f64; 3], pub vel: [f64; 3] }
#[derive(Clone, Debug, PartialEq)]
pub struct Scene { pub nuclei: Vec<SceneNucleus>, pub charge: i32, pub multiplicity: Option<u32>, pub grid_n: usize, pub grid_h: f64, pub sigma: Option<f64> }

impl Scene {
    pub const PRESETS: &'static [&'static str] = &["h", "h2", "he", "lih", "h2o"];
    pub fn preset(name: &str) -> Option<Scene> {
        let text = match name {
            "h" => include_str!("../presets/h.scene"), "h2" => include_str!("../presets/h2.scene"), "he" => include_str!("../presets/he.scene"),
            "lih" => include_str!("../presets/lih.scene"), "h2o" => include_str!("../presets/h2o.scene"), _ => return None,
        };
        Some(Scene::parse(text).expect("preset parses"))
    }
    pub fn parse(text: &str) -> Result<Scene, String> {
        let (mut grid, mut charge, mut mult, mut sigma, mut nuclei) = (None, 0i32, None, None, Vec::new());
        for (i, raw) in text.lines().enumerate() {
            let line = raw.split('#').next().unwrap().trim();
            if line.is_empty() { continue; }
            let t: Vec<&str> = line.split_whitespace().collect();
            let num = |s: &str| s.parse::<f64>().map_err(|_| format!("line {}: bad number '{s}'", i + 1));
            match t[0] {
                "grid" if t.len() == 3 => grid = Some((t[1].parse::<usize>().map_err(|_| format!("line {}: bad n", i + 1))?, num(t[2])?)),
                "charge" if t.len() == 2 => charge = t[1].parse().map_err(|_| format!("line {}: bad charge", i + 1))?,
                "multiplicity" if t.len() == 2 => mult = Some(t[1].parse().map_err(|_| format!("line {}: bad multiplicity", i + 1))?),
                "sigma" if t.len() == 2 => sigma = Some(num(t[1])?),
                "nucleus" if t.len() == 5 || t.len() == 8 => {
                    let z = t[1].parse::<u8>().map_err(|_| format!("line {}: bad Z", i + 1))?;
                    let pos = [num(t[2])?, num(t[3])?, num(t[4])?];
                    let vel = if t.len() == 8 { [num(t[5])?, num(t[6])?, num(t[7])?] } else { [0.0; 3] };
                    nuclei.push(SceneNucleus { z, pos, vel });
                }
                other => return Err(format!("line {}: unknown or malformed directive '{other}'", i + 1)),
            }
        }
        let (grid_n, grid_h) = grid.ok_or("missing 'grid n h' line")?;
        Ok(Scene { nuclei, charge, multiplicity: mult, grid_n, grid_h, sigma })
    }
    pub fn to_text(&self) -> String {
        let mut s = format!("# atomic sandbox scene v1\ngrid {} {}\ncharge {}\n", self.grid_n, self.grid_h, self.charge);
        if let Some(m) = self.multiplicity { s += &format!("multiplicity {m}\n"); }
        if let Some(x) = self.sigma { s += &format!("sigma {x}\n"); }
        for n in &self.nuclei {
            s += &format!("nucleus {} {} {} {}", n.z, n.pos[0], n.pos[1], n.pos[2]);
            if n.vel != [0.0; 3] { s += &format!(" {} {} {}", n.vel[0], n.vel[1], n.vel[2]); }
            s.push('\n');
        }
        s
    }
}

Solve runs with `ScfSettings::for_grid` plus `sigma` override; `tol = 1e-5` (interactive; documented). The density is converted to `f32` on the worker. `seq` increments per solve.

```rust
//! Simulation worker: owns the qm state, runs SCF off the render thread, publishes immutable snapshots.
use crate::scene::{Scene, SceneNucleus};
use qm::{scf, Energy, Grid, KsState, Nucleus, ScfSettings, System};
use std::sync::mpsc::{channel, Receiver, Sender, TryRecvError};
use std::sync::Arc;
use std::thread::JoinHandle;
use std::time::{Duration, Instant};

pub enum Command { SetScene(Scene), MoveNucleus { index: usize, pos: [f64; 3] }, AddNucleus { z: u8, pos: [f64; 3] }, RemoveNucleus(usize), SetCharge(i32), SetMultiplicity(Option<u32>), SetGrid { n: usize, h: f64 }, SetSigma(Option<f64>), Shutdown }

pub struct Snapshot { pub scene: Scene, pub grid_n: usize, pub grid_h: f64, pub origin: [f64; 3], pub density: Arc<Vec<f32>>, pub density_max: f32, pub energy: Energy, pub iterations: usize, pub max_eigen_residual: f64, pub poisson_residual: f64, pub warnings: Vec<String>, pub solve_ms: u64, pub seq: u64 }
pub enum Event { Snapshot(Snapshot), Error { seq: u64, message: String }, Busy(bool) }

pub struct SimWorker { tx: Sender<Command>, rx: Receiver<Event>, handle: Option<JoinHandle<()>> }

/// Interactive SCF tolerance: looser than the oracles' 1e-7 so a 49³ H₂ solve is ~1 s.
const INTERACTIVE_TOL: f64 = 1e-5;

impl SimWorker {
    pub fn spawn(initial: Scene) -> SimWorker {
        let (ctx, crx) = channel::<Command>();
        let (etx, erx) = channel::<Event>();
        let handle = std::thread::Builder::new().name("sim".into()).spawn(move || worker(initial, crx, etx)).expect("spawn sim thread");
        SimWorker { tx: ctx, rx: erx, handle: Some(handle) }
    }
    pub fn send(&self, cmd: Command) { let _ = self.tx.send(cmd); }
    pub fn try_recv(&self) -> Option<Event> { self.rx.try_recv().ok() }
    pub fn recv_timeout(&self, d: Duration) -> Option<Event> { self.rx.recv_timeout(d).ok() }
}
impl Drop for SimWorker {
    fn drop(&mut self) { let _ = self.tx.send(Command::Shutdown); if let Some(h) = self.handle.take() { let _ = h.join(); } }
}

struct Local { scene: Scene, warm: Option<KsState>, seq: u64 }

/// Applies a command; returns true if the warm state must be discarded.
fn apply(local: &mut Local, cmd: Command) -> bool {
    let s = &mut local.scene;
    match cmd {
        Command::SetScene(new) => { let reset = new.grid_n != s.grid_n || new.grid_h != s.grid_h || new.nuclei.len() != s.nuclei.len(); *s = new; reset }
        Command::MoveNucleus { index, pos } => { if let Some(n) = s.nuclei.get_mut(index) { n.pos = pos; } false }
        Command::AddNucleus { z, pos } => { s.nuclei.push(SceneNucleus { z, pos, vel: [0.0; 3] }); true }
        Command::RemoveNucleus(i) => { if i < s.nuclei.len() { s.nuclei.remove(i); } true }
        Command::SetCharge(c) => { s.charge = c; true }
        Command::SetMultiplicity(m) => { s.multiplicity = m; true }
        Command::SetGrid { n, h } => { s.grid_n = n; s.grid_h = h; true }
        Command::SetSigma(x) => { s.sigma = x; false }
        Command::Shutdown => false,
    }
}

fn worker(initial: Scene, rx: Receiver<Command>, tx: Sender<Event>) {
    let mut local = Local { scene: initial, warm: None, seq: 0 };
    let mut pending = true; // solve the initial scene
    loop {
        // block for the first command only when nothing is pending
        if !pending {
            match rx.recv() { Ok(Command::Shutdown) | Err(_) => return, Ok(c) => { if apply(&mut local, c) { local.warm = None; } pending = true; } }
        }
        // drain the rest (coalesce)
        loop {
            match rx.try_recv() {
                Ok(Command::Shutdown) | Err(TryRecvError::Disconnected) => return,
                Ok(c) => { if apply(&mut local, c) { local.warm = None; } }
                Err(TryRecvError::Empty) => break,
            }
        }
        pending = false;
        local.seq += 1;
        let seq = local.seq;
        let _ = tx.send(Event::Busy(true));
        let t0 = Instant::now();
        let scene = local.scene.clone();
        let warm = local.warm.take();
        let result = std::panic::catch_unwind(std::panic::AssertUnwindSafe(|| solve(&scene, warm.as_ref())));
        match result {
            Ok(Ok((state, snap))) => { local.warm = Some(state); let _ = tx.send(Event::Snapshot(Snapshot { solve_ms: t0.elapsed().as_millis() as u64, seq, ..snap })); }
            Ok(Err(e)) => { let _ = tx.send(Event::Error { seq, message: e }); }
            Err(p) => { let msg = p.downcast_ref::<String>().cloned().or_else(|| p.downcast_ref::<&str>().map(|s| s.to_string())).unwrap_or_else(|| "solver panicked".into()); let _ = tx.send(Event::Error { seq, message: msg }); }
        }
        let _ = tx.send(Event::Busy(false));
    }
}

fn solve(scene: &Scene, warm: Option<&KsState>) -> Result<(KsState, Snapshot), String> {
    let grid = Grid::cube(scene.grid_n, scene.grid_h);
    let nuclei: Vec<Nucleus> = scene.nuclei.iter().map(|n| Nucleus { pos: n.pos, z: n.z }).collect();
    let total: i32 = nuclei.iter().map(|n| n.z as i32).sum::<i32>() - scene.charge;
    if total < 0 { return Err(format!("charge {} exceeds the {} protons", scene.charge, total + scene.charge)); }
    if let Some(m) = scene.multiplicity { let n = total as usize; if m < 1 || (m as usize - 1) > n || (n - (m as usize - 1)) % 2 != 0 { return Err(format!("multiplicity {m} impossible for {n} electrons")); } }
    let system = System::new(nuclei, scene.charge, scene.multiplicity);
    let mut settings = ScfSettings::for_grid(&grid);
    settings.tol = INTERACTIVE_TOL;
    if let Some(s) = scene.sigma { settings.sigma = s; }
    let (state, stats) = scf(&grid, &system, &settings, warm).map_err(|e| e.to_string())?;
    let rho = state.rho();
    let density: Vec<f32> = rho.iter().map(|&x| x as f32).collect();
    let density_max = density.iter().cloned().fold(0.0f32, f32::max);
    let snap = Snapshot { scene: scene.clone(), grid_n: scene.grid_n, grid_h: scene.grid_h, origin: grid.origin, density: Arc::new(density), density_max, energy: stats.energy, iterations: stats.iterations, max_eigen_residual: stats.max_eigen_residual, poisson_residual: stats.poisson_residual, warnings: stats.warnings, solve_ms: 0, seq: 0 };
    Ok((state, snap))
}
```
