# M3 handoff — GPU solver: results, deferred items, notes for M4 (dynamics)

Written 2026-10-13 at the close of M3 (`qm-gpu` crate + GPU backend in the viewer). Final whole-branch review: ready to merge, no Critical/Important findings; doc-only fix wave landed.

## What M3 delivered

A wgpu/WGSL port of the Kohn-Sham solver that reproduces the f64 CPU reference at fixed σ:

| System (49³, σ = h = 0.25, tol 1e-6) | |ΔE| GPU − CPU | bound |
|---|---|---|
| H | 1.5e-7 Ha | 1e-6 |
| He | 1.0e-6 | 2e-6 |
| H₂ | 5.9e-7 | 2e-6 |
| LiH | 3.1e-7 | 3e-6 |
| H₂O | 2.35e-7 | 2e-5 |

Forces agree to ≤ 2e-5 Ha/Bohr; the H₂ curve shape to 1e-6. Timing (solo, RX 7900 XTX): 49³ H₂ cold 206 ms / warm 108 ms (CPU: 5–7 s); 57³ H₂O 1.8 s (CPU: 116 s); 97³ H₂O cold 3.57 s. The viewer's GPU backend shows the cloud ~1 s after a drag release for H₂ and keeps 240 Hz while solving; drags cancel stale solves at SCF-step granularity.

Design facts that later milestones must keep: padded f32 fields `(i+4) + P(j+4) + P²(k+4)`; every grid reduction is two-level (f32 workgroup tree → f64 Neumaier over ≤ 1024 partials × dv); small dense algebra in f64 on the CPU; analytic erf V_nuc (6e-9 fit); `PoissonStats.residual` and `EigenStats.max_residual` are TRUE residuals with `Stop` reasons (Floor/Converged/Stagnated → use the result; MaxIter → warning); `SolveProfile` separates informational `notes` from actionable `warnings`; solves are bit-deterministic; the density texture handed to the viewer is unpadded x-fastest R32Float.

## Known f32 floors (measured)

Poisson true-residual floor ≈ 6e-6 (33³) … 2e-5 (97³) — request tol 1e-8 inside the SCF; LOBPCG residual floor ≈ 1.8e-6 at h = 0.25 (model 2.4e-8·‖T‖) — eig tol = max(settings, 3×floor); GPU energy path scatter ≈ 6e-7 Ha (H₂) to 5e-6 (H₂O) between solve paths — any energy-difference feature must budget for it (random-walk ≈ 3e-5 Ha over 10³ MD steps).

## Solver prerequisites for M4 (do these first)

1. **Err, not panic, on non-finite state.** `eigen.rs` `assemble` (non-finite Gram), rank-loss assert, `cholesky().expect`; `poisson.rs` `rz > 0` / `pap > 0` asserts (NaN compares false → panic). Today `app::sim` catches the unwind and rebuilds the solver; MD needs an `Err` it can react to (halve dt, retry) without rebuilding a 0.3 s / 227 MB solver. Keep the device-loss `expect`s.
2. **Orbital lag (MD's common case).** At interactive tol 1e-5 the eigen tol (3×floor ≈ 5.4e-6, hysteresis band to 8.1e-6) admits ~5e-5 of density lag; frozen orbitals get re-solved by potential drift late in the SCF (DIIS reset; warm 15 steps vs cold 9 on H₂ 49³; force error ~2e-4 Ha/Bohr first order). Remedy 1: per-call eigen tol tied to the running Δρ. Details and rejected variants: `docs/superpowers/notes/2026-10-13-m3-task10-orbital-lag.md`. Measure with the deterministic readback witness (`app::sim::moving_a_nucleus_warm_starts`).
3. **Per-step cost levers (latency, not FLOPs):** uniform ring (per-dispatch `create_buffer` dominates at ~70 dispatches/LOBPCG iteration); cache the forces' partials/staging pair (forces run every MD step); in-kernel R_lm evaluation (drops 227 MB at 97³ and the 300 ms setup); residual replacement in CG (lowers the V_H floor — the term that set H₂O's old 1.2e-5); extrapolate ρ_in across steps (2ρ_t − ρ_{t−1}) before the first Poisson solve.

## The honest MD gap

49³ H₂ warm ≈ 0.1 s/step → with dt = 0.25 fs, ≈ 2.5 fs of simulated time per wall second: an H₂ stretch period (~10 fs) takes ~4 s wall; 1 ps ≈ 7 min. 97³ H₂O warm 1.75 s/step → one bend period ≈ 60 s wall. "Watch it move" is viable for small molecules at 49³; large grids are 10–100× short of interactive. The levers above are the path; FLOPs are not the bottleneck (≈ 5 ns/point).

## Physics constraints for the dynamics suite

- **Egg-box forces:** Σ_I F_I ≈ 3e-4 Ha/Bohr for O at σ = h = 0.25 on BOTH solvers (agree to 2e-5). Do not assert momentum conservation below that; a documented COM net-force correction is legitimate.
- **Energy conservation** carries the f32 path scatter (~6e-7 Ha/solve); NVE drift thresholds must say so.
- Spec §9.3 targets stand: H₂ vibration within ~10 % of 4400 cm⁻¹ (LSDA shift documented), NVE drift bound over ~1 ps, thermostat reaches target T.
