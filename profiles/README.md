# Profiles

Saved profiles (`.profile` files): the app's layout and look (dock tabs and widths, view and density settings, units). Save one from **File ▸ Profiles…**, commit it here to share it, and anyone can load it from the same window. Display settings only: a profile never changes the physics.

The state you are using is kept separately, per user, in `%LOCALAPPDATA%tomic-sandbox\current.profile`, so the app opens as you left it.
